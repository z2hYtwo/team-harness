# 发布工作流

## 概述
管理从准备到部署的完整发布流程。

## 阶段

### 1. 发布准备
- 创建发布分支
- 更新版本号
- 生成变更日志
- 审查依赖

### 2. 发布测试
- 运行完整测试套件
- 执行冒烟测试
- 进行 UAT 验收
- 安全扫描
- 技能: `/testing`

### 3. 发布文档
- 更新发布说明
- 记录破坏性变更
- 更新部署指南
- 准备回滚方案

### 4. 部署
- 部署到预发环境
- 验证预发部署
- 部署到生产环境
- 监控指标

### 5. 发布后
- 打 Git Tag
- 发布公告
- 监控问题
- 处理 Hotfix（如需要）

## 进入条件
- 所有特性已完成并合并
- QA 已签收
- 相关方已批准

## 退出条件
- 成功部署到生产环境
- 无严重问题
- 发布已记录
- 团队已通知
