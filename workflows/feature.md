# Feature Development Workflow

## Overview
This workflow guides the complete process of developing a new feature from requirement analysis to deployment.

## Stages

### 1. Requirement Analysis
- Parse user requirements and clarify ambiguities
- Define acceptance criteria
- Identify constraints and dependencies
- Skill: `/requirement-analysis`

### 2. Architecture Design
- Design technical architecture
- Choose technology stack
- Define component interfaces
- Skill: `/architecture-design`

### 3. Task Planning
- Break down into implementation tasks
- Estimate effort and timeline
- Identify risks
- Skill: `/task-planning`

### 4. Implementation
- Write production code
- Follow coding standards
- Document complex logic
- Skill: `/implementation`

### 5. Testing
- Write unit tests
- Write integration tests
- Perform manual testing
- Skill: `/testing`

### 6. Code Review
- Self-review checklist
- Peer review preparation
- Address feedback
- Skill: `/code-review`

## Entry Criteria
- Clear feature requirement from stakeholder
- Product/design approval

## Exit Criteria
- All tests passing
- Code reviewed and approved
- Documentation complete
- Feature deployed to production
