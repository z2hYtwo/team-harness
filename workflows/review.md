# 代码审查工作流

## 概述
全面的代码审查流程，确保质量和知识共享。

## 阶段

### 1. 预审查清单
- 自查已完成
- 测试通过
- 文档已更新
- CI/CD 检查通过

### 2. 审查执行
- 检查代码正确性
- 验证测试覆盖率
- 审查安全隐患
- 评估性能影响
- 技能: `/code-review`

### 3. 反馈与讨论
- 提供建设性反馈
- 讨论设计替代方案
- 澄清需求

### 4. 问题解决
- 处理审查意见
- 重大修改需再次审查
- 达标后批准

### 5. 合并与监控
- 合并到目标分支
- 监控部署
- 关注异常

## 进入条件
- Pull Request 已创建
- 所有 CI 检查通过
- 提供了描述和上下文

## 退出条件
- 所有评论已解决
- 获得必要的审批
- 成功合并
