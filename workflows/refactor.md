# Refactor Workflow

## Overview
Improve code structure and maintainability without changing functionality.

## Stages

### 1. Analysis
- Identify code smells
- Measure current metrics (complexity, duplication)
- Define refactoring goals

### 2. Planning
- Plan refactoring steps
- Identify affected components
- Assess risk
- Skill: `/task-planning`

### 3. Refactoring
- Apply refactoring patterns
- Maintain test coverage
- Keep commits atomic
- Skill: `/implementation`

### 4. Verification
- Ensure all tests still pass
- Verify no behavior changes
- Check performance impact
- Skill: `/testing`

### 5. Review
- Code review
- Document changes
- Update architecture docs
- Skill: `/code-review`

## Entry Criteria
- Code quality concerns identified
- Stakeholder approval for effort

## Exit Criteria
- Code quality improved
- All tests passing
- No functionality changes
- Documentation updated
