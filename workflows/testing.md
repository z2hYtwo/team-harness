# 测试工作流

## 概述
涵盖单元测试、集成测试和端到端测试的全面测试策略。

## 阶段

### 1. 测试规划
- 定义测试范围
- 识别测试用例
- 准备测试数据
- 技能: `/task-planning`

### 2. 单元测试
- 测试独立组件
- Mock 外部依赖
- 达到目标覆盖率
- 技能: `/testing`

### 3. 集成测试
- 测试组件交互
- 测试数据库集成
- 测试 API 契约
- 技能: `/testing`

### 4. 系统测试
- 端到端场景测试
- 性能测试
- 安全测试

### 5. 测试审查
- 审查测试质量
- 检查覆盖率指标
- 重构测试代码
- 技能: `/code-review`

## 进入条件
- 代码实现已完成
- 测试环境已就绪

## 退出条件
- 达到目标覆盖率
- 所有测试通过
- 测试代码已审查
- CI/CD 集成完成
