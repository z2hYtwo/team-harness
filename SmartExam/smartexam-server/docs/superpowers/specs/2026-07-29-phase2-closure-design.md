# SmartExam Phase 2 收口设计

> 日期：2026-07-29
> 状态：已确认推进方案，待书面设计复核

## 1. 目标

完成 SmartExam Phase 2“题库与 AI 出题预留”阶段的工程收口，使异步题目导入导出能力具备可验证、可观测、可维护的生产基础，并将项目进度文档校准到代码真实状态。

## 3. 收口范围

### 3.1 异步任务领域验证

为 `QuestionIoTaskServiceImpl` 与 `QuestionIoTaskWorker` 增加聚焦测试，覆盖：

1. 导入任务创建、源文件落盘和异步调度。
2. 导出任务创建、查询参数序列化和异步调度。
3. 任务仅允许创建者本人查询和下载；管理员保留全局管理能力。
4. 非成功任务、缺少结果路径和非法结果路径不能下载。
5. 导入任务成功、部分失败、整体失败时的状态、进度和计数一致。
6. 导出分页处理、最大导出行数限制和结果文件生成。

### 3.2 结果下载语义

保留统一端点 `GET /api/v1/questions/tasks/{id}/result`，不再增加重复的“错误明细”端点：

- 导出任务的结果文件是题目导出文件。
- 导入任务存在失败记录时，结果文件是错误明细 Excel。
- 导入任务全部成功时不生成无业务价值的空错误报告，任务响应中的 `resultFilename` 为空，前端不展示下载按钮。
- 任务执行异常使用 `FAILED` 状态和脱敏后的 `errorMessage` 表达，不暴露服务器文件路径或堆栈。

### 3.3 进度与可观测性

- `QUEUED`：进度为 0。
- `RUNNING`：按已处理数量计算进度，最高为 99。
- `SUCCESS`：进度为 100；成功数与失败数之和等于已处理数。
- `FAILED`：保留最后一次处理进度和计数，不伪装为 100。
- Worker 记录任务 ID、类型、耗时、处理数量和最终状态，不记录题目正文、答案、令牌或服务器绝对路径。

### 3.4 数据库迁移验证

以独立验证库执行 Flyway V1-V6，验证：

- V5/V6 可在 V1-V4 基线上顺序升级。
- `question_generation_task` 与 `question_io_task` 的字段、索引和默认值符合实体映射。
- 重复执行 Flyway 不产生额外变更。
- 不清空、不重建默认开发库，不修改已发布迁移脚本；若发现问题，仅新增后续修复迁移。

### 3.5 前端收口

保持现有题目页任务抽屉结构，仅完善状态表达：

- 展示处理数、成功数、失败数和进度。
- 只有存在 `resultFilename` 的成功任务显示下载操作。
- 导入部分失败时将下载操作标记为“下载错误明细”。
- `FAILED` 状态展示后端返回的安全错误摘要。
- 轮询仅在抽屉打开且存在 `QUEUED`/`RUNNING` 任务时运行，离开页面时释放定时器。

## 4. 架构与职责

```text
QuestionIoTaskController
        │ REST、参数校验、附件响应
        ▼
QuestionIoTaskService
        │ 权限边界、任务生命周期、下载校验
        ├──────────────► QuestionIoTaskFileService
        │                受控目录内的文件读写
        ▼
QuestionIoTaskWorker
        │ 异步编排、进度、计数、状态转换
        ├──────────────► QuestionService
        │                复用题目领域校验与持久化
        ▼
QuestionIoTaskMapper
                         任务状态持久化
```

- Controller 不包含业务逻辑。
- Service 负责用户数据边界和任务状态规则。
- Worker 负责异步执行，不直接复制题目领域校验。
- FileService 负责路径归一化和受控目录校验，防止路径穿越。
- Mapper 只负责持久化。

## 5. 错误处理

- 可预期业务错误转换为 `BusinessException` 和标准错误码。
- 文件格式错误记录为导入行错误，不中断其他有效行。
- 无法读取源文件、无法写入结果文件或序列化失败使任务进入 `FAILED`。
- 日志保留完整服务端异常用于运维，API 仅返回安全摘要。
- 文件清理与保留策略不在本阶段自动删除，避免误删尚未下载的结果；后续由运维阶段增加定时清理。

## 7. 安全与性能

- 下载前校验任务所有权和任务状态。
- 结果路径必须位于配置的任务存储根目录。
- 导入继续使用流式读取和批次错误写入；导出继续分页读取，避免将全量题目加载到内存。
- 保留最大导出行数配置，防止单任务耗尽数据库和磁盘资源。
- 前端按需轮询，避免无运行任务时持续请求。
